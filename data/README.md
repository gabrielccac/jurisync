# Local runtime data

Save private API responses, PJe documents, polling state, and temporary files here.
The contents are ignored by Git except this README. Ignoring a file is not encryption.
No old account exports or credentials were copied during consolidation.

Juridiq defaults to an external LocalAppData/Juridiq token cache keyed by the configured
email. Use JURIDIQ_SESSION_FILE only with a distinct path for each account.
The imported 1G watcher writes its cookie cache and baseline here by default.
